# HR Analytics Dashboard 📊

## Project Overview

The **HR Analytics Dashboard** is a data analytics project developed to analyze employee attrition patterns and identify the key factors influencing employee turnover.

This project focuses on understanding employee behavior by analyzing workforce data and discovering patterns related to employee attrition. The complete analytics workflow includes data exploration using Python, data analysis using SQL, and interactive visualization using Tableau Public.

The main objective of this project is to transform raw HR data into meaningful business insights that help organizations improve employee retention strategies and make data-driven decisions.

---

# Dataset

**Dataset Name:** IBM HR Analytics Employee Attrition & Performance Dataset

**Source:** Kaggle

**Number of Records:** 1,470 employee records

The dataset contains employee-related information that helps analyze workforce trends, employee behavior, and attrition patterns.

This dataset was used to perform exploratory analysis, SQL-based analysis, and dashboard visualization to identify the major factors contributing to employee attrition.

# Key Business Insights

- Employees working overtime have a higher likelihood of leaving the organization.
- Attrition patterns differ across various departments and job roles.
- Employees with lower years of experience show noticeable attrition trends.
- Certain job roles contribute significantly to employee turnover.
- Workforce characteristics and work conditions influence employee retention.
- Identifying attrition factors helps organizations develop effective employee retention strategies.
